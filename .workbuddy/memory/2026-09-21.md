### Design decisions
- **"Paper & ink" cinematic theme** — warm cream `#faf7f2`, ink `#1a1614`, accent
  crimson `#b23a2c` + gold `#a97d2a`. Chosen to read as "literary + film" rather than
  generic dev-portfolio.
- **Typography**: Fraunces (display serif) + Inter (body) + system mono for labels.
  Google Fonts link with full system fallbacks.
- **Dark mode toggle** with `localStorage('dc-theme')`, also honours
  `prefers-color-scheme`. All colours are CSS custom properties so theming is one block.
- Hero portrait is a **film-frame card** with CSS filmstrip perforations and a "DC"
  monogram (no photo asset exists in the repo) plus two floating chips.
- Pipeline rendered as **CSS clip-path chevron flow bar** + 6 detail cards.
- Motion: scroll progress bar, IntersectionObserver reveal + active-nav highlighting,
  all disabled under `prefers-reduced-motion`.
